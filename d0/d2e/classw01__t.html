Detailed Description

w01_t::w01_t ( const dsp * R_W0,
const dmat * R_W1,
int R_nxx )

Copy the bilinear weighting W0 (sparse) and W1 (vector) to GPU. W0 of fully illuminated points is represented by the constant W0v and index list W0f, while that of partially illuminated points is kept as sparse W0p.

Parameters
[in]R_W0Sparse bilinear weighting W0.
[in]R_W1Vector weighting W1 for piston removal.
[in]R_nxxSize of the fitting grid along x.
