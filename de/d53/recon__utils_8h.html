Apply turbulence invpsd to xin in Fourier space, scaled by alpha and add to xout. Not thread safe for the same block: A holds the work space. Concurrent callers need a private copy of A (see setup_recon_mvr_mvm_iact()).

Parameters

[in]AThe invpsd_t struct. Its fftxopd is used as work space.
[in]xinThe input.
[in]alphaScaling factor.
[in]xbBlock index. If -1, do all blocks.
[in]ybBlock index. Do nothing if xb != yb, since we apply to diagonal only.

void psfr_calc ( sim_t * simu,
dcell * opdr,
dcell * dmpsol,
dcell * dmerr,
dcell * dmerr_lo )

Compute and save PSF reconstruction telemetry. For pseudo open loop estimations, like high order loop, we add opdr to, and subtract dmpsol from the OPD. For closed loop estimations, like ahst low order or lsr, we add dmerr_lo, and dmerr to the OPD.

Parameters
[in,out]simuThe simulation struct. simu->ecov is accumulated into.
[in]opdrTomography output (pseudo open loop estimate) on xloc. May be NULL.
[in]dmpsolDM commands used for pseudo open loop gradients. May be NULL.
[in]dmerrHigh order closed loop DM error signal. May be NULL.
[in]dmerr_loLow order closed loop error signal (NGS modes). May be NULL.
