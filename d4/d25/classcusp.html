cusp::cusp ( const dsp * src_csc,
int tocsr = 0,

Copy a CPU sparse matrix to GPU. See utils.cu.

Convert a host dsp array to GPU sparse array, optionally converted to CSR and/or transposed. Index and value arrays are deduplicated if cuda_dedup is set.

Parameters
[in]src_cscSource dsp in CSC. Nothing is done if NULL.
[in]tocsr0: Keep in CSC. 1: Convert to CSR.
[in]transp1: transpose.

void cuspmul ( curmat & y,
const cusp & A,
const curmat & x,
long ncolvec,
char trans,
Real alpha,
stream_t & stream )
friend

Sparse matrix multiplication y+=alpha*op(A)*x where A is sparse. x, y are vectors or matrices. (Slow for GS0.) Uses the cuSparse generic API for CUDA version 11 and later which removed the old API.

Parameters
[in,out]yOutput vector or matrix, accumulated into. Its dense descriptor is created and cached if not yet existing.
[in]ASparse matrix (CSR or CSC). Its SpMV/SpMM work buffer is allocated or enlarged as needed.
[in]xInput vector or matrix. Its dense descriptor is created and cached if not yet existing.
[in]ncolvecNumber of columns in x and y. 1 for vector.
[in]trans't' or 1 to use transpose of A, otherwise use A.
[in]alphaScaling factor of the product.
[in]streamStream whose cusparse handle is used.
