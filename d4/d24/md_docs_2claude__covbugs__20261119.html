Library bugs found by the coverage tests, 2026-11-19

Commit: "Fix library bugs found by the coverage tests". The tests from the previous commit are updated to assert the correct behavior. All 34 programs (324 cases) pass in the C (with CUDA) and C++ builds. maos_check.sh 5 on GPU and CPU is within run-to-run noise; CPU single conjugate cases match the reference exactly.

Changes that can alter results

  • lib/libmisc.c addnoise: the flat-field correction multiplied by QE instead of dividing, so the mean was (signal+background)*qe^2-corr (qe=0.5, signal 100, background 20, corr 15 gave 15 instead of 105). Now (randp(tot*qe)+rne*n)/qe-corr, matching cuda/sim/wfsgrad.cu. Affects CPU physical optics only when powfs.qe is set (empty by default). Added a size assert on qe. (cmocka_libmisc misc_addnoise)
  • math/spmm.c complex X(spmulsp2): 't' and 'c' were swapped (X(sptrans) already conjugates for complex types). maos/fdpcg.c relied on the swap; its calls are changed to "cn"/"nc", so the FDPCG preconditioner is unchanged. test/cmocka_fdpcg.c likewise. (cmocka_sparse: all 9 n/t/c combinations against dense)
  • lib/mtch.c mtch: residual background terms in the intensity and constraint columns are now scaled by kpx (kpy for y). Matters only when background is not fully subtracted (bkgrndc!=1 or bkgrnd2!=bkgrnd2c). (cmocka_wfs wfs_mtch)
  • lib/servo.c servo_isstable: phase-margin comparison now has a 1e-6 rad tolerance. Type II servo_optim rejected every gain due to round off and returned tiny gains; affects skyc with servo type 2. (cmocka_servo servo_optim_type2)
  • lib/turbulence.c spatial_psd: a reused output was not zeroed (genscreen's spectrum cache reuses it).

sys

  • bin.c zfread: FITS block padding was skipped only for size>1, so int8 data left the stream misaligned. Header cards are read with zfread_do. (cmocka_fits fits_raw, int8 moved to the middle)
  • readstr.c readstr_num: *endptr not set on failure, so readstr_numarr looped forever on "1 abc". Also fixes an uninitialized endptr in readcfg for blank values.
  • readstr.c readstr_strarr: overflowed the array after a non-fatal error() for too many entries; NULL dereference on an unmatched quote; unmatched brackets and blank strings/entries handled.
  • readstr.c parse_expr: trailing operator ("1+") now fails (returns NaN / -1) instead of using the partial value.
  • sockio.c udp_recv: drop packets with index outside [0,npacket) or headers shorter than 12 bytes; first peek requires a full header and npacket>0.
  • sock.c listen_port: quit_listen reset on entry and quit_time/ lasttime made local, so it can be restarted; pfd, pfd_handler, npfd freed on exit; only removes opt.localpath if it bound it.
  • sockio.c wrap_io: invalid mode returns -1 instead of looping on EINTR.
  • misc.c argv2str: trailing delimiter trim never ran.
  • misc.c mydirname: "/" and "/a" return "/"; NULL after overflow error.
  • Return after error(): zfopen (zstd failure), mmap_open (ftruncate failure; also fn2 leak), mymkdir, cmd_string (unterminated quote), parse_argopt (array option without value), thread_new (pthread_attr_destroy), thread_pool_init (pthread_create failure).
  • Not changed: mem_new returning nref=0 is by design (callers take a ref).

math

  • spmm.c X(cellmm): infinite recursion on unhandled shapes / NULL output element; now passes &P(*C0,0) and errors out otherwise. (cmocka_cell cell_mm)
  • mat.c X(celldropempty): leaked the container for dim==1 and the dropped empty blocks for dim==2.
  • blas.c X(invspd_inplace), X(inv_inplace): empty input is a no-op, non-square errors out, and failures no longer write posv.bin/gesv.bin. X(cellinvspd_each) skips empty blocks and handles NULL.
  • matmath.h: removed declaration of the never-defined X(interp1_2).
  • matmath.c X(rectangle): area overestimated up to 12% for rotated rectangles; now under 0.7%. Only used by mex/aolib.
  • mathmisc.c calc_gcd/calc_lcm: infinite recursion on negative input; maxminlong read p[0] for N==0.
  • matmath.c X(islinear)/X(islog): accept decreasing coordinates, reject n<2 and zero spacing; X(interp1) arbitrary-spacing branch handles either direction.
  • sp.h: declared X(mm_cell).
  • matmath.c X(dot): returned -1 for empty input, breaking X(celldot) and pcg with empty blocks (muv_bgs alg=1); now 0. X(celldot) returns 0 on mismatch. The muv_bgs CG block solver check in cmocka_recon is enabled.
  • Return after error() in blas.c (mm, chol), spmm.c (parse_trans, spmv, spmm_do), cell.c (cellinit returns int, cellinit2, celldim), mat.c (2cell, cell2m, cellreduce + leak, refcols, cols, cellsub, ...), matmath.c (add, addcol, corr, clip, spline_prep, trapz, cellcat, cwm, histfill, gauss_fit, twopoint), sp.c (spwdot, spscalex/y, spdiag, spfull, spadd2, spcat, spcell2sp, spinvbdiag), fft.c (NULL plans), loc.c (embed, extract, reduce, loctransform), map.c, matmmap.c, spbin.c.
  • Left: failure-time debug dumps in blas.c/matmath.c (error_chol_A, A_svd_failed, ...) still write files on LAPACK failure or NaN.

lib

  • servo.c servo_test: leaked noise. cn2est.c cn2est_est: leaked Pnk.
  • turbulence.c calc_aniso2: NaN when hc2<hc1; uses fabs.
  • readcfg.c:471: strcmp on NULL for a renamed key with empty value.
  • kalman.c sde_fit: no longer writes psdi/coeff/bad_cov .bin files.
  • psd.c psd_vibid: short input returns empty; second filter stage starts from the first; a peak open at the end of range is kept.
  • mkdtf.c smooth(): applied per profile column (was broken for >1 profile).
  • phase.c gerchberg_saxton: divide by zero for zero amplitude; embed centering now matches dembed for odd sizes; checks rmod.
  • cure.c: lx initialized to NaN (invalid first subaperture in a row); cure_loc frees grad on the error path.
  • petal.c petal_connect: correct for a fully measured ring (closure error spread linearly); petal_free frees otf; petal_mkopd returns NULL for an invalid mode.
  • zernike.c cov_vonkarman leaked CC; KL_vonkarman_do leaked modu. Tip/tilt underestimate investigated: caused by coarse low frequency sampling, not changed.
  • pywfs.c pywfs_free frees saloc (balances maos/powfs.c locref); pywfs_simu uses pycfg->siglev.
  • genotf.c genotf_wrap: || -> && in validation; genotf validates area and opdbias sizes.
  • bessel_mode.c: J1'(0)=+0.5 (was wrong sign; not reached in practice).
  • Return after error() in psd.c, servo.c, cn2est.c, kalman.c, pywfs.c, petal.c, libmisc.c, locfft.c, mkdtf.c, stfun.c, mkg.c, laplacian.c, mkh.c, slaving.c, gensei.c.

Tests

cmocka_recon muv_bgs uses 30 BGS iterations for every block solver and checks the solution. Leak checks were done with valgrind (UNITTEST_MAIN sets LOG_LEVEL=-4, which hides the MAOS_MEM_DEBUG report).
