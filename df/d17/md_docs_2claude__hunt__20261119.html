Second review of sys, math, lib, maos, skyc, tools, cuda and mex, 2026-11-19

Commit: "Fix bugs from a second review of sys, math, lib, maos, skyc, tools, cuda, mex" (base e6403afd3). The review looked for bugs not already covered by claude_bugs_20261119.md and claude_review_20261119.md.

Verification: full build with CUDA has no warnings; make check passed (23 programs at the time); maos_check.sh 5 on GPU with MAOS_MEM_DEBUG=1 is within run-to-run noise and shows no new leaks. Not exercised at runtime: CPU-only paths, skyc, mex (no mex.h on the test machine).

Changes that can alter results

  • lib/pywfs.c pywfs_ints: the modulation-shift copy loop used iy<ny2/ ix<nx2, but ny2/nx2 are counts from iy0/ix0 (as in cuda/sim/pywfs.cu). For negative modulation offsets the last rows/columns of the PSF were dropped. Small change to CPU PWFS intensities, gradoff, optical gain (pywfs_tt, run at setup even with GPU) and the CPU interaction matrix.
  • lib/pywfs.c pywfs_new: tmp-redefine?round(tmp):0 parsed as (tmp-redefine)?...; parenthesized to tmp-(redefine?round(tmp):0). Only when pywfs.psx/psy are nonzero.
  • lib/cn2est.c cn2est_new: fy had zero frequency at the center while fx and the comment use FFT order, making mc alternate sign along y. Now fy=(iy<nm2?iy:iy-nm)*df. Changes Cn2/r0 estimates for baselines not along x, y or 45 degrees (e.g. 5 or 6 LGS rings).
  • math/matmath.c X(interp1linear), X(interp1log): an xnew exactly at the last grid point returned ydefault; it is now interpolated (relative tolerance 1e-6). Affects lib/psd.c and skyc nonlinearity lookups.
  • maos/parms.c readcfg_siglev: if(!nwfs) continue skipped advancing the per-wavelength index, so later powfs read the wrong wvlwts, telthruput, atmthruput, mag and magbkgrnd when an empty powfs came first.
  • maos/parms.c readcfg_fov (rect/square, clip=1): clipped points left (0,0) entries in thetax/thetay, i.e. extra on-axis directions with weight 1. Arrays are resized to the kept count.
  • maos/parms.c setup_parms_postproc_recon: the auto sim.eplo (servo_optim_margin) result was discarded, always giving 0.5 (also when sim.ephi<=0 since eplo defaults to ephi). Now assigned, when dtrat_lo>0.
  • maos/recon_tomo.c setup_recon_tomo_reg (tomo.cxxalg=1/2): invpsd and fractal are applied once (not as L2'L2), so they now take the full cxxscale*TOMOSCALE instead of its square root.
  • maos/wfsgrad.c (i0save): with i0save==2 the CPU added ints to itself (doubling images before gradients); with i0save==1 nothing was saved. Now accumulates into simu->intsout for any i0save, as on GPU.
  • maos/powfs.c setup_powfs_calib: pixthetax/pixthetay swapped for pixoff.
  • maos/utils.c shwfs_grad (CORR/CORRS): reference used WFS 0's i0; now PR(i0,isa,wfsind).
  • maos/perfevl.c perfevl_ievl: atmscale applied in CPU evl with atm.dtrat>0 while CPU wfsgrad and GPU skip it. Now atmscale&&!atm.dtrat.
  • maos/dither_utils.c dither_post, wfsgrad_sa_drift: gradoffdrift was sized by the dithered powfs's WFS count but indexed by global iwfs (heap overflow), and created only for the first dithered powfs. Now sized nwfs; each dither==1 powfs fills its entries; readers check NULL.
  • maos/ahst.c ngsmod_remove (ahst_wt==4): used the 1x1 Mtmp_lo as an ndm x 1 product (error with 2+ DMs) and stopped at nmod although Modes2 has nmod+1 columns. Uses a local temp and the right bound.
  • maos/recon_setup.c setup_recon_focus: saneai(iwfs,iwfs) used the physical index in GLAO; now the wfsr index.
  • skyc/star.c setup_star_read_pistat: dadd(&tmp,0,...) in the wavelength loop kept only the last wavelength's NEA; now a weighted sum (bc=1). Affects skyc.neaaniso=1.
  • skyc/skysim.c skysim_isky: with psd_ws and addws=0, residual wind shake was added to phyres at selection and again when reporting (and appeared in "ATM NGS"). phyres is now ATM only; ws is added to the selection metric and reported total. res_ws is indexed 0 with multirate (was out of bounds).
  • skyc/parms.c setup_parms: wavelength weight used qe/thruput[iwvl] instead of the matched jwvl, and kept a stale weight when unmatched.
  • skyc/genpistat.c wfs_nonlinearity: sanea read as interleaved x/y (isa*2, isa*2+1) but is stored x then y (isa, isa+nsa). Cached in powfsd_nonlin; delete the cache to see the change.
  • skyc/powfs.c setup_powfs_dtf: pixpsa/2-0.5 integer division put the detector half a pixel off for odd pixpsa; now pixpsa*0.5-0.5.
  • cuda/sim/wfsints.cu: uplink tip/tilt added only if ttx!=0&&tty!=0; now || as on CPU (llt_ws puts all wind shake on x).
  • cuda/sim/wfsinit.cu gpu_wfsgrad_init: bkgrnd/bkgrndc column test was inverted (ny==1): out-of-range column for single-column input, WFS 0's background for per-WFS input. Now ny>1.
  • cuda/sim/pywfs.cu pywfs_ints: detector stage ran inside the wavelength loop on an accumulating PSF, so nwvl=2 gave 2*w0+w1. Moved after the loop.
  • cuda/sim/perfevl.cu calc_ptt_do: missing __syncthreads() before threads read the reduction result (data race).
  • cuda/sim/wfsgrad.cu: DM ray tracing used wfs.misregx/y directly instead of the SH-only gated values; idealwfs/wfsalias dmproj passed misreg 0; psfout ztiltout pushed gradcalc instead of gradacc.
  • cuda/recon/moao.cu gpu_dm2gpu_embed: negative (ghost) map indices read out of bounds with fit.square=0; now labs(iphi) as in CPU prop().
  • sys/process_linux.c get_usage_running: MATLAB thread test inverted, so maos/skyc jobs counted as one thread. Changes scheduler admission only.
  • sys/readstr.c readstr_strarr: returned the count without relax-filled entries, so a single string for all powfs/WFS (e.g. powfs.qe=["f"]) was ignored by the ==npowfs checks in parms.c. Now returns len.

sys

  • misc.c islink (and mex/io.c copy): used stat(), so links were never detected and zfopen("w") overwrote a link's target. Now lstat().
  • misc.c parse_argopt: double array options were truncated with (int); an array option without a value called strtol(NULL).
  • readstr.c readstr_numarr: transposed input with more than len values over-read the buffer; now an error.
  • readstr.c trim_string: read one byte before an empty string.
  • scheduler_client.c init_hosts: s into char[64]; now %63s. print_backtrace_symbol: reject len<=0.
  • daemonize.c redirect: unchecked fopen of the log file.
  • process.c init_process: fclose(NULL) when /proc/meminfo is missing.
  • process_linux.c: get_job_progname readlink overflow by one byte; get_job_mem/get_job_launchtime used uninitialized values on read failure.
  • bin.c mmap_open: leaked fn2 when opening for read failed.

math

  • spbin.c X(spreaddata): complex sparse files (M_CSP*/M_ZSP*) could not be read; added the cases.
  • sp.c X(spaddI): for nx<ny inserted entries past nzmax for columns without a diagonal.
  • loc.c `X(embed_locstat)`, `loc_coord2ind`; map.c `create_metapupil` (pad), `map_blend`: used dx where dy was needed (wrong only when dx!=dy).
  • loc.c `loc_circle_add`: inner radius bound wrong for r<1.5dx (tiny circles).
  • loc.c `loc_ellipse_add`: ellipse was about 1.41x too large (r2=2).
  • loc.c `loc_reduce_sp`, `loc_reduce_spcell`: remapped unused slots up to nzmax; now up to `pp[ny]`.
  • loc.c `loctransform_do`: non-integer powers below the integer were treated as integer (missing fabs); negative powers indexed `xp[-1]`.
  • loc.c `loc_keywords`: 120-byte buffer truncated long values; now 256.
  • cell.c `readdata_auto`: leaked an empty unwrapped cell; `writedata` (async) wrote a header to a NULL fp for NULL elements.

lib

  • slaving.c `slaving` (mode 2): `actcpl0[-1]`/`group[-1]` for edge actuators; `groupc` one element short.
  • pcg.c `pcg`: NaN step (0/0 for zero RHS or exact convergence) not caught; now `!isfinite(ak)` as on GPU.
  • mkg.c `mkg_ngs`: index checks fired for absent modes (index 0), breaking TT-only skyc configs.
  • accphi.c `LINEAR_ADD_NONGRID`: no bounds check although `prop_nongrid*` rely on it; now `loc_map_get`.
  • readcfg.c `open_config_full` (`+=`/`-=`): crashed or wrote `data[-1]` with an empty value. `readcfg_peek_n`: NULL data for `key=`.
  • gensei.c `gensei` (i0scale): rescaling inside the wavelength loop lost the wavelength weighting; now once after accumulation.
  • locfft.c `locfft_psf`: preallocated output was not zeroed.
  • turbulence.c `spect_screen_do`: leaked scale references with r0logpsds.
  • accphi_grid_do.c `prop_grid_block`: compared y with `wrapx`.
  • genotf.c `genotf`: cov size check used `NX(amp)` (NULL deref, false error).
  • mkh.c `mkht`: `locin->iac before the NULL check.
  • psd.c psd2ts: imax not clamped to nstep.
  • pywfs.c pywfs_new: leaked a reference to a self-created loc.
  • draw.c draw_helper: continued after socketpair/fork failure; listen_drawdaemon: closed an fd that is closed again later (now shutdown).
  • zernike.c cov_diagnolize: S not resized with kl.
  • kalman.c sde_kalman`: optional Cnn dereferenced.

maos (no result change on valid default configs)

  • parms.c setup_parms_postproc_seeds and utils.c remove_lock: fnlock was not compacted with seeds/fdlock (wrong lock removed, remove(NULL), double close, close(0)); getcwd fallback not terminated.
  • parms.c: atm.size y check (nx<Nmax||nx<Nmax); atmr.os not compacted with ht/wt; free on dmat sabad; config strings never freed (powfs saloc, amp, bkgrndfnc, i0load, llt.ttpsd, lsr.fnreg, sim.dmadd, load.*).
  • powfs.c setup_shwfs_etf, free_powfs_shwfs: etfsim/etfsim2 aliasing caused use-after-free and double free; new etf_release().
  • surf.c setup_surf: ncpa.ttr indexed shared amp out of bounds; ncpa.rmsci NULL DM.
  • utils.c wait_dmreal, filter.c, recon.c, sim_utils.c shift_grad: tv_nsec+=1e6 not wrapped (busy spin).
  • maos.c find_var: NULL recon/powfs in evlol; help string one byte short.
  • setup.c: || in an assert that should be &&.
  • perfevl.c (evl.psfol==2): unlocked accumulation from several threads.
  • wfsints.c: lotfc leaked per wavelength.
  • sim_utils.c: save->dm_evl sized nwfs, indexed by ievl; zoompos_icol advanced per powfs; atmscale and dmprojsq leaked; progress plot rows did not match the legend; save_skyc NULL llt.
  • sim.c maos_sim: final mean ignored sim.start (NaN).
  • twfs.c twfs_setup_GR: powfs[-1] when itpowfs==-1.
  • recon_tomo.c (load.tomo): wrong file names and a leaked double read.
  • recon_setup.c setup_recon_saneai: load.saneai checked nwfs instead of nwfsr and leaked; sabad indexed with the wfsr index.
  • recon_utils.c cn2est_isim: static counter overran cn2res on seed 2 (bounds guard; a per-simu counter would be the real fix).
  • moao.c: actcpl leaked. recon_geom.c: dither_m leaked. fdpcg.c: pp[nxp*nxp] should be pp[nxp*nyp].

skyc and tools

  • skyc/powfs.c setup_powfs_dtf (fnpsf1): P(psf2x,ix,iy) on a vector overflowed the heap.
  • skyc/parms.c: remove(arg->confcmd) could delete the user's config file; removed. Seed lock compaction (as in maos). dbg only raised to 1.
  • skyc/skysim.c skysim_calc_psd: wrote psds[1] when gsplit=0; skysim_isky leaked stars without asterisms and used an uninitialized nstar.
  • skyc/physim.c skysim_save: wrote pixtheta[1] (out of bounds) in radians.
  • tools/scheduler.c: dup'd socket not closed after SCM_RIGHTS (fd leak per drawdaemon/maos client); bad drawdaemon sockets not closed; uninitialized CMD_TRACE buffer printed; monitor_send_do length not clamped.
  • tools/scheduler_proxy.c: fd_remote stored an fd closed right after, later closing an unrelated fd.
  • tools/drawres.c: NULL dts dereferenced; leaks of dts, res0, seed2.
  • tools/bin2fits.c: VLA one byte short for ".fits".
  • tools/load.c: read before short argv strings; dup2 failure never detected.

mex

  • interface.h d2l, l2d, mx2dsp, mx2csp: NULL input dereferenced.
  • io.c procfn: leaked fn2.
