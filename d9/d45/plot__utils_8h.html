ploted all the different beam directions as points. style is defined as follows: bits 1-3:the point style. bit 4: whether points are connected. bits 5-8: size bits 9-32:color

The color follows RGB representation: (Since 2011-02-18) bits 32-25: Red. bits 24-17: Green. bits 16-9: Blue.
