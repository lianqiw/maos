Detailed Description

Fourier domain preconditioner (FDPCG) for the tomography with conjugate gradients. The preconditioner approximates the tomography left hand side matrix in the Fourier domain with periodic boundary conditions, where it is block diagonal after grouping the spatial frequencies of all layers that couple through the subaperture sampling.

Create aperture selection function that selects the gradients for valid subapertures from ground layer xloc (or ploc).

2012-04-06: Found that by clipping xsel in FD, the strength of xsel in the spatial domain (SD) is reduced because of reduced strength of xsel in FD. Need to renormalize xsel in FD to have the same total, which corresponds to the center value in SD.

clipping xsel in FD essentially removed the boundary conditiona, making infinite subapertures. The sum of xsel in FD has to be 1.

Parameters
[in]nxGrid size along x.
[in]nyGrid size along y.
[in]dxGrid sampling (m).
[in]salocSubaperture lower left corner coordinate.
[in]saaNormalized subaperture area. Subapertures with area above 0.9 are selected.
Returns
Newly allocated Fourier domain convolution operator of the selection function. The caller frees it.

Create a permulation acting on xhat (fft of x on xloc) so that points of the same spatial frequency in all layers are grouped together.

In this implementation, it implies that all the screens have the same spatial sampling frequency, or they have the same tot spatial size.

The ray tracing couples the screens but only on points with same or harmonic spatial frequencies. Group them together.

shift=1: apply a fftshift with permutation vector. half=1: only using (half+1) of the inner most dimension (FFT is hermitian for real matrix)

Parameters
[in]nxGrid size along x of each layer.
[in]nyGrid size along y of each layer.
[in]osOver sampling ratio of each layer relative to the subaperture.
[in]bsSize of each diagonal block.
[in]npsNumber of layers.
[in]shiftWhether to apply fftshift in the permutation vector.
[in]halfWhether to only use about half of the frequencies.
Returns
Newly allocated permutation vector. Negative entries indicate a conjugate is needed. The caller frees it.

Assemble the Fourier domain preconditioner matrix: the inverse PSD of each layer plus, for each WFS, the propagation of the layers to the ground, followed by the gradient operator and subaperture selection, weighted by the inverse of the NEA squared: Mhat=diag(invpsd)+sum_wfs prop'*(gx'*sel'*sel*gx+gy'*sel'*sel*gy)*prop/nea^2.

Parameters
[in]npsNumber of layers.
[in]nxGrid size along x of each layer.
[in]nyGrid size along y of each layer.
[in]nxpGround (ploc) grid size along x.
[in]nypGround (ploc) grid size along y.
[in]dxpGround grid sampling (m).
[in]salocSubaperture lower left corner coordinate.
[in]saaNormalized subaperture area. Subapertures with area above 0.9 are selected.
[in]invpsdInverse PSD of all layers concatenated (nxtot x 1), with the zero frequency at the center.
[in]nwfsNumber of WFS.
[in]dispxDisplacement along x of each layer for each WFS (m), nps x nwfs.
[in]dispyDisplacement along y of each layer for each WFS (m), nps x nwfs.
[in]neaiNEA of each WFS (rad).
[in]iwfsWFS number of each WFS, used in the file names when save is set. May be NULL to use the index.
[in]saveSave the intermediate matrices to files fdpcg_*.
Returns
Newly allocated matrix. The caller frees it.

Apply the Fourier domain preconditioner. Preconditioner solves xout=M^-1*xin where M is the preconditioner matrix. Here M^-1 is applied in Fourier Domain via xout=IFFT(M*FFT(xin));
