LGS MCAO (default)

The default configuration default.conf uses mcao_lgs.conf, which is a generic LGS MCAO system. It includes mcao_base.conf and wfs_lgs_ttf_tt.conf, which in turn include the following files to define all the parameters.

  • sim.conf to define some general parameters. It includes keck.conf (examples/keck.conf) for the telescope aperture.
  • dm_dual.conf to define the dual deformable mirrors (conjugated to 0 and 11.8 km)
  • atm/atm_mk13n50p.conf to define the turbulence profiles using the Maunakea 13N median seeing
  • fov_sq34.conf which is composed of the following
    • evl_sq34.conf to define the science fov for performance evaluation.
    • fit_sq34.conf to define the DM fitting fov
  • recon.conf to define the parameters about turbulence reconstruction and DM fitting
  • dbg.conf to define debugging and saving/loading geometry and telemetry.
  • wfs_lgs_ttf_tt.conf to define the wavefront sensors which is composed of the following
    • powfs_none.conf to clear the WFS list. It includes powfs_common.conf for the common WFS parameters.
    • powfs_shlgs.conf for six Shack-Hartmann LGS WFS. It uses llt_CL.conf for the laser launch telescope (powfs.fnllt).
    • powfs_shttf.conf for one tip/tilt/focus NGS WFS (it includes powfs_shtt.conf).
    • powfs_shtt.conf for two tip/tilt NGS WFS (it includes powfs_shngs.conf).

The TMT NFIRAOS configuration examples/nfiraos_lgs.conf is mcao_lgs.conf with the TMT aperture (examples/tmt.conf) and NFIRAOS specific parameters.
