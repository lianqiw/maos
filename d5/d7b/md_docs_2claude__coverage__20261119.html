Unit test coverage of sys, math and lib, 2026-11-19

Commit: "Add unit tests to improve code coverage".

Line coverage of sys/, math/ and lib/ by make check (gcov, --enable-gcov) went from 53.7% to 86.1% (16038 of 18619 lines). 34 programs, 324 test cases; all pass in the C and C++ builds in about 13 s. No test writes files or leaves /dev/shm segments.

New programs (test cases)

  • cmocka_sock (12): TCP/UDP/unix sockets, stio/stread/stwrite, listen_port with responders, udp_send/udp_recv, scheduler message helpers, in-process only.
  • cmocka_sysutil (8): process info, path helpers, time/format helpers, locking, environment readers.
  • cmocka_map (9): map_t/rmap_t creation, embedding, metapupil, rotation.
  • cmocka_cell (16): cell init/reshape/cat/drop-empty, cellmm, cellinvspd, celldot.
  • cmocka_mathmisc (9): gcd/lcm, permutations, max/min, factorial, sorting.
  • cmocka_wfs (14): mkg, mkz, mkdtf/smooth, genotf, gensei, mtch, cure, Gerchberg-Saxton phase retrieval.
  • cmocka_recon (12): pcg, muv (direct, CG, SVD, block Gauss-Seidel), laplacian, slaving.
  • cmocka_modes (11): Zernike, KL, Bessel modes, petal modes and solver.
  • cmocka_pywfs (4): pyramid WFS setup, simulation, gradients, gain.
  • cmocka_servo (11): servo filters, optimization, servo_test, Kalman/sde_fit.
  • cmocka_cfg (8): readcfg parsing, override, rename, arrays, strings.
  • cmocka_libmisc (13): addnoise, loc_calib, hysteresis, cn2est, comb, turbulence helpers (calc_aniso, spatial_psd).

Extended programs

cmocka_sys (8 -> 16), readstr (2 -> 9), fits (10 -> 11), mat (2 -> 8), matmath (3 -> 15), blas (1 -> 7), sparse (8 -> 10), loc (9 -> 14), psd (2 -> 12). Memory leaks in the existing tests were fixed.

Not covered

Code that needs real files, a running scheduler or a drawing daemon: sys/daemonize.c, sys/zfarr.c, most of sys/scheduler_client.c, the file cache paths of lib/pywfs.c and lib/gensei.c, and file/mmap/async paths of sys/bin.c.

Library bugs found

The tests were written to pass with the behavior at the time; the bugs they found were fixed in the next commit (see claude_covbugs_20261119.md).
