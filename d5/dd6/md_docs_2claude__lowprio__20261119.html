Remaining low-priority lib fixes from the second review, 2026-11-19

Commit: "lib: fix remaining low-priority issues from the second review". These fixes were made by the user, checked and completed by Claude.

  • lib/accphi_grid_do.c: removed a leftover debug print.
  • lib/chol.c:
    • chol_save/chol_read stored and read the native cholmod factor values using real, which is wrong when cholmod uses a different precision than MAOS (e.g. --disable-double). Added M_CHOL_REAL and use chol_real.
    • After reading, L->dtype was not set; now set to CHOL_DTYPE.
    • Fixed a typo in #undef READDBL.
  • lib/kalman.c:
    • sde_fit: the window around a vibration peak could extend outside the PSD so the interpolation anchors indexed out of range. The window is clamped: if(i2+2>NX(psd2)) i2=NX(psd2)-2; if(i1<1) i1=1;.
    • kalman_read leaked the dthi entry and the cell container.
  • lib/petal.c: npetal<=1 divided by zero; it now reports an error.
