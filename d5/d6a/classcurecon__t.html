Set up the tomography right hand side (RR) and left hand side (RL) solvers in GPU according to tomo.alg (CBS, CG with optional FDPCG, or SVD). Skipped if MVM is used and already available. Also called to update the control parameters.

Update the tomography operators after the turbulence profile (cn2) is updated: ray tracing, laplacian regularization, and FDPCG preconditioner. For predictive tomography, layer wind velocities are also updated.

◆ moao_filter()

void curecon_t::moao_filter ( dcell * _dm_wfs,
dcell * _dm_evl )

Apply a low pass filter with gain gdm to the MOAO DM commands for WFS and evaluation directions: dm=(1-g)*dm+g*dm_new, in the GPU that owns each direction. The results are copied to _dm_wfs and _dm_evl if needed by CPU.

Parameters
[in,out]_dm_wfsMOAO DM commands of WFS on CPU. Elements are updated if not NULL or if WFS is not simulated in GPU.
[in,out]_dm_evlMOAO DM commands of evaluation directions on CPU. Elements are updated if not NULL or if evaluation is not done in GPU.
