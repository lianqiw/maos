Detailed Description

Routine to generate detector transfer function and elongation transfer function due to sodium layer.

Data Structure Documentation

◆ dtf_t

struct dtf_t

contains the data associated with a detector transfer function for a subaperture. The PSF is computed as \(\textrm{PSF}=\frac{1}{N^2\sum(\textrm{amp}^2)}|\textrm{fftshift}\mathcal{F}[A \exp(-\frac{2\pi}{\lambda}\textrm{opd})]|^2\). The subaperture image is computed as \(I=\textrm{si}*\mathcal{F}^{-1}[\mathcal{F}[\textrm{PSF}\times\textrm{nominal}]]\)

mkdtf() computes the parameters used to sample PSFs onto detectors in the Fourier domain. It incorporates size of the detector pixels, and charge diffusion. For polar coordinate detectors, it also rotates the pixels and pixel coordinates so that they are aranged along the radial and azimuthal direction.

Parameters
[in]wvlsList of wavelength (m).
[in]dxsaSubaperture size (m).
[in]embfacEmbedding factor (2).
[in]notfxFFT size along x.
[in]notfyFFT size along y.
[in]pixpsaxNumber of pixels along x(r).
[in]pixpsayNumber of pixels along y(a).
[in]pixthetaxPixel size along x (r) (radian).
[in]pixthetayPixel size along y (a) (radian).
[in]pixoffxOffset of image center from center of pixel array, along x or radial, in unit of pixel. Can be NULL.
[in]pixoffyOffset of image center from center of pixel array, along y or azimuthal, in unit of pixel. Can be NULL.
[in]pixblurPixel blur sigma (fraction of pixel).
[in]pixrotRotation angle of pixels islands in each subaperture. For polar coordinate only. Can be NULL.
Returns
Newly allocated array of nwvl dtf_t; free with dtf_free().

Compute the elongation transfer function (ETF) for LGS WFS subapertures from the sodium profile. The DTF nominal is fused into the ETF.

Parameters
[in]dtfsThe dtfs, one per wavelength.
[in]sodium_The sodium profile. In each cell first column is coordinate (m). Different cells must have the same coordinate. Can also be a dmat.
[in]icolWhich sodium profile column to use (wrapped).
[in]srotRotation angle of each subaperture (radian). Required.
[in]srsaSubaperture to LLT distance (m).
[in]hsLGS WFS focus altitude (m).
[in]htelTelescope altitude (m).
[in]za_radZenith angle (radian).
[in]no_interpUse direct sum instead of interpolation + FFT. Slower.
Returns
Newly allocated array of nwvl etf_t; free with etf_free().
Parameters
