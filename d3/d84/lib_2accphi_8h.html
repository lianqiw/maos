◆ prop_prep()

int prop_prep ( real * displacex,
real * displacey,
real * alpha,
real * scale,
propdata_t * propdata )

Compute the ray tracing geometry from propdata: the displacement (displacex, displacey) at the input layer, the amplitude scaling alpha (including angle of incidence), and the cone effect scaling factor scale. Fills defaults of propdata->alpha (1) and propdata->hs (infinity).

Parameters
[out]displacexDisplacement along x at the input layer (m).
[out]displaceyDisplacement along y at the input layer (m).
[out]alphaAmplitude scaling including angle of incidence.
[out]scaleCone effect scaling factor.
[in,out]propdataRay tracing parameters; defaults of alpha and hs are filled in.
Returns
1 if valid, 0 if the layer is above the guide star.

A wrapper prop routine that handles all the different cases by calling the different routines. Handles threading.

Parameters

[in]startFirst output index (point, subaperture, or row) to process.
[in]endOne past the last output index to process. 0 means all.
