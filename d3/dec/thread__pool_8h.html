◆ thread_pool_queue()

void thread_pool_queue ( tp_counter_t * counter,
thread_fun fun,
void * arg,
int njob,
int urgent )

Queue jobs that belongs to group denoted by counter. counter->group will be incremented by 1 for each job queued and decreased by 1 after each job is finished. Wait on it will clear when count is decreased to zero.

Job is added to jobsnormal or joburgent depending on urgent value

Parameters
[in,out]counterJob group counter.
[in]funFunction to call with arg for each job. If NULL, arg is an array of thread_t and each valid element's own fun is called with it.
[in]argArgument of fun, or array of njob thread_t if fun is NULL.
[in]njobNumber of jobs.
[in]urgentWhether the jobs are urgent.

Wait for jobs in the count to be done. Does jobs while waiting. Has the potential to deadlock if it calls do_job and the job inside calls pthread_cond_wait.

Parameters
[in]counterJob group counter to wait for.
[in]urgentWhether to only do urgent jobs while waiting.
