lmat * comb_stars ( lmat * nwfsmax,
lmat * starvalid,
int flag )

Determine all valid combinations of stars for all wfs. Assume that the stars are sorted in descending S/N order. valid is set to -1 for stars that need to be skipped. Only implemented for npowfs=1 or npowfs=2. If no valid combination is found, the number of wfs is reduced and the search is retried.

Parameters
[in]nwfsmaxnpowfs*1 array for maximum number of wfs
[in]starvalidnstar*npowfs array for validity of star at powfs mode. -1 means invalid
[in]flag0: keep order. nstar should be equal to nwfstot. do not reorder stars. Only 1 combination. 1: regular. 2: make wfs[0] brighter than wfs[1] (stars are sorted from bright to dim).
Returns
Newly allocated nwfstot*ncomb array with the star index of each wfs (wfs of powfs 0 first) for each combination, or NULL if none is valid. The caller frees it.
