◆ wrap_io()

ssize_t wrap_io ( int sfd,
void * p,
const size_t len,
int mode )

Wrap io function and handle partial operations. Uses send()/recv() for sockets and write()/read() otherwise. Retries on EINTR and stops at end of file or closed connection.

Parameters
[in]sfdSocket or file descriptor.
[in,out]pBuffer to write from or read into.
[in]lenNumber of bytes to transfer.
[in]mode1 or 'w' for write, 0 or 'r' for read.
Returns
Number of bytes successfully transferred, or -1 on error or invalid mode.

int udp_send ( udp_t * info,
char * buf,
size_t len,
int counter )

Use UDP socket to send data reliably. Data is split into packets of info->payload bytes including header. Afterwards listens for resend requests from udp_recv() until it reports completion or times out.

Parameters
[in]infoUDP connection information.
[in]bufData to send.
[in]lenNumber of bytes to send.
[in]counterFrame counter written in each packet header.
Returns
0 if sent, -1 if info is invalid.

◆ udp_recv()

int udp_recv ( udp_t * info,
char ** pbuf,
size_t * len )

Use UDP socket to receive data reliably from udp_send(). Requests resend of missing packets and acknowledges when done.

Parameters
[in]infoUDP connection information.
[in,out]pbufReceive buffer. Reallocated if NULL or too small; the caller frees it.
[in,out]lenSize of *pbuf in bytes. Updated if reallocated; set to 0 on failure.
Returns
Frame counter of the received data, or -1 on failure.
