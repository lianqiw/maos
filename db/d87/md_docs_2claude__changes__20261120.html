Configuration and file format

  • dbg.wfs_iac is read as a real number.
  • The mcao and keck examples that failed the powfs.astscale check have the base asterism halved and astscale doubled (guide stars unchanged). The check skips powfs whose WFS are all on axis, which fixes the strata examples. skyc_ttf.conf uses current keys.
  • Single precision complex FITS files had re and im exchanged for other readers (astropy, cfitsio). zmat FITS files written by earlier versions now read back with re and im exchanged. .bin files are not affected.
  • FITS: long keywords use CONTINUE cards; int8 data padding; files of 2 GB or more; DM grid maps keep iac, dratio and aoi.

Other changes (no effect on results)

  • Robustness fixes: crashes, out of bounds access, leaks, NULL checks, return after error() (which is recoverable in tests and mex), zstd seeking, shared memory files, sockets, thread pool waits, and scheduler/monitor/drawdaemon issues.
  • Security: an empty ~/.aos/htcookie bypassed the scheduler's web authentication; htpasswd/htcookie were world readable.
  • The scheduler connection regression from 88beaf2da (non-blocking connect_port) is fixed.
  • C++ build (CC=g++): configure library checks, ADDR() for compound literals, no function pointer casts (UBSan), const void* qsort comparators.
  • macOS: process information (memory, load, CPU, launch time) is implemented; SO_NOSIGPIPE on sockets; realloc_maos(p,0) frees on every platform; mymalloc/myrealloc parenthesize the count.
  • configure: --disable-threadlib with OpenBLAS, the CUDA and mex checks.
  • Python: maos_client.py protocol fixes, maos_result.py with NumPy >= 1.24.
  • CI: the Linux gcc job builds with CUDA (compiled, not run).
  • maos -h and the documentation describe the current options.

Unit tests

  • The old test_* programs are replaced by 34 cmocka programs with 324 test cases that assert results and use no temporary files. Line coverage of sys, math and lib is 86% (was 54%).
  • make check writes docs/unittest_status.md in the build folder; make doc includes it, with coverage when configured with --enable-gcov.

Verification

  • No warnings in C with CUDA, C++ without CUDA, and C++ without OpenMP.
  • make check passes in these builds and with clang -fsanitize=undefined (no reports). valgrind is clean, except cmocka_matops, cmocka_recon and cmocka_servo, which did not finish within 25 minutes.
  • maos_check.sh 5 on GPU and CPU is within noise, and targeted runs were done for the GPU fixes, Cn2 tomography, dithering, GLAO and pistatout.
  • Not run: skyc, the scheduler and the GTK tools (compiled only), mex (no Matlab), macOS and BSD code (not compiled here).

Not changed

  • X(minsearch): zero components of the initial guess give a degenerate simplex.
  • mkw_annular: the inner and outer normalizations do not cancel exactly; fixing it changes the fitting weights of annular pupils.
  • wfspupmask in maos/powfs.c is unused; its radius is always d/2.
  • skyc/powfs.c calls dinterp1 with a 2-D xnew, which it rejects.
  • maos/petal_utils.c keeps its static thread variables; tools/memdbg.c does not compile as C++.
