Unit tests converted to cmocka, with a status report, 2026-11-19

Commit: "Convert unit tests to cmocka and add a test status report".

Rules for the tests

  • Every test asserts results (the old test_* programs mostly printed or wrote files for manual inspection).
  • No test reads or writes a temporary file. Inputs are generated in memory and file format round trips go through a pipe.
  • Tests that were commented out in the old programs are enabled.

Infrastructure

  • test/unittest.h: common header. Includes aos.h, then cmocka.h inside extern "C" (the installed cmocka.h has no C++ guard, and its fail() macro breaks <ios> if included first). Provides:
    • unittest_near(); assert_float_equal is redefined to compare in double precision (cmocka's version casts to float, making tight tolerances meaningless).
    • assert_dmat_near(A,B,tol).
    • UNITTEST_MAIN(...): installs a dummy signal handler so error() does not abort, and sets LOG_LEVEL=-4.
  • m4/my_check_cmocka.m4: cmocka is also enabled for C++ builds.
  • test/Makefile.am: lists all cmocka_* programs; LOG_DRIVER is test/unittest_driver.sh.
  • test/unittest_driver.sh: runs automake's test-driver, then test/unittest_report.sh under a mkdir lock (parallel make check).
  • test/unittest_report.sh: parses cmocka RUN/OK/FAILED/SKIPPED lines of every *.log and writes docs/96_unittest.md (\page page96_unittest): build info (compiler, C/C++, precision, CUDA, git revision), summary, per-case table and a Failures section with the failing assertion lines. A program that crashes in the middle of a test reports that case as ERROR.
  • docs/90_devel.md links the page; CLAUDE.md describes the tests.

Library additions needed by the tests

  • sys/bin.c zfdopen_as(fd, mode, suffix): open a descriptor as a given format (.bin/.fits, compressed or not), so round trips can use pipes.
  • math/cell.c readbin_fp(fp, id, level): read any array from an open file_t, including FITS cells.
  • sys/misc.c: strnadd() and argv2str() crashed on NULL entries; stradd() computed the buffer size wrong. (Found by cmocka_sys.)

Programs (test cases)

Removed: test_mat, test_plot, test_draw, test_rand, test_sparse, test_cmat2, test_fft, test_proj, test_loc, test_chol, test_accphi, test_fd, test_atm, test_fractal.

New:

  • cmocka_sys (8): string helpers, argument parsing, expression parsing.
  • cmocka_matops (17): dmat creation, reference counting, reshape, arithmetic, norms, BLAS products, inverse/SVD/pinv, cell operations (from test_mat).
  • cmocka_cmat (12): complex matrices, embed/extract, FFT shift, abs2 (from test_cmat2).
  • cmocka_fft (8): 1D/2D, real/complex, partial FFT, against direct DFT.
  • cmocka_rand (5): reproducibility and moments of randu/randn/randp/lrand.
  • cmocka_sparse (8): sparse create/convert/multiply/add/transpose against dense.
  • cmocka_chol (6): Cholesky factor/solve, sparse RHS, convert to sparse.
  • cmocka_loc (9): loc creation, embed, map conversion, mkh interpolation.
  • cmocka_accphi (8): ray tracing map/loc/stat in all modes agrees with reference and between methods.
  • cmocka_proj (5): projection of tilted surfaces.
  • cmocka_fdpcg (5): Fourier domain preconditioner pieces (from test_fd).
  • cmocka_atm (7): turbulence screen statistics, spectrum, reproducibility.
  • cmocka_fractal (7): fractal screens, forward/inverse round trip, covariance.

Rewritten:

  • cmocka_fits (9): .bin and .fits round trips through a pipe, all types, cells, keywords, compressed formats.
  • cmocka_threadpool (2), cmocka_rayleigh (3), cmocka_locfft (8).

Total: 22 programs, 138 test cases, all passing in C and C++ builds.
