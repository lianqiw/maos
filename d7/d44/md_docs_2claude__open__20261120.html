Fixes for the open items of the second review, 2026-11-20

Commit: "Fix the open items from the second review". Fixes the "Still open" list of claude_hunt_20261119.md. Each item was confirmed to still exist before it was fixed. Three bugs found while testing are also fixed (marked "new").

Verification:

  • C build with CUDA and C++ build (CC=g++): no warnings.
  • make check: 34 programs pass in both builds.
  • maos_check.sh 5 on GPU and CPU: within run-to-run noise (see the commit report).
  • Targeted runs:
    • GPU partial atm screen (forced with a temporary memory cap) against the full screen;
    • GPU vs CPU uplink OPD for a side-launched LLT, with idealfsm and pistatout;
    • ahst_idealngs with powfs.skip;
    • fieldstop;
    • MVM with tomo.cxxalg=1, 16 threads vs 1 thread (bitwise identical);
    • GLAO with save.gradpsol and save.gcov;
    • PWFS multi-mode dithering;
    • pistatout with pistatstc=0.
  • skyc, the scheduler and mex were compiled but not run. mex was not even compiled: there is no Matlab on the test machine.

Changes that can alter results

  • cuda/sim/wfsints.cu: the uplink turbulence was ray traced at llt->misreg, not at the launch location. It now uses ox/oy as the CPU does. GPU and CPU uplink OPD agree to 2e-12. This changes side-launched or off-axis LLT results; on-axis launch is unchanged.
  • cuda/sim/wfsints.cu: pistatout overwrote fsmreal with the ideal uplink tilt. With idealfsm, telws, llt_ws and ltpm were also added on top of it. Now only idealfsm sets the ideal tilt, and otherwise wfsgrad_llt_tt runs, as on CPU.
  • cuda/sim/wfsgrad.cu (tomo.ahst_idealngs): ideal NGS modes were applied to WFS with powfs.lo set. They are now applied to WFS with powfs.skip set, as on CPU.
  • maos/recon_geom.c setup_recon_dither_dm: 1-id/dither_nd used integer division, so the dither amplitude was never reduced. It is now 1.-(real)id/dither_nd. Affects PWFS multi-mode dithering (powfs.dither<-1 with recon.modal=1).
  • maos/powfs.c setup_shwfs_geom: the corner test was always true, so the whole padded grid was kept.
    • A subaperture is now kept if its nearest point is inside the outer radius and its farthest corner is outside the central obscuration. Both radii are widened by WFS and aperture misregistration.
    • locresize is used so that locy moves with the new count.
    • All default SH powfs use saat>0, so their subaperture set is unchanged.
    • With saat=0 the fully dark subapertures are dropped. For example, a 60x60 grid goes from 3844 to 2904 subapertures.
  • math/bessik.c beschb: used Numerical Recipes' float-precision Chebyshev term counts (5/5). It now uses 7/8. K and I go from about 1e-9 to about 1e-14 relative error. This changes the von Karman covariance by about 1e-9.
  • maos/wfsgrad.c (new): pistatout was accumulated before pistatstart but normalized by the number of steps after it. With pistatstc=0 this also crashed, because gradcalc was NULL before pistatstart. Both are now keyed on do_pistat.

File format

  • sys/bin.c writearr, math/mathmisc.c readvec, mex/read.c, mex/write.c: single-precision complex (zmat, 8 bytes per element) was byte swapped as one 8-byte unit in FITS, which exchanged re and im for other readers (astropy, cfitsio). Each component is now swapped separately. Double complex was already right.
    • zmat FITS files written by earlier versions now read back with re and im exchanged. .bin files are not affected.
    • New helper magic_iscomplex() in sys/bin.h.
  • sys/bin.c async_init: the async (hole punching) writer did not handle FITS. It now returns NULL for FITS.
    • X(writedata) and cell writedata with ncol==-1 skip the async setup.
    • The data is written synchronously when the object is freed (X(free_content), cellfree_do), which covers dnew_file and dcellnew_file with .fits names.
  • sys/bin.c zfwrite (FITS) and mex/io.c, mex/write.c: int lengths overflowed for 2 GB or more; they are now long.
  • math/map.c map_make_keywords: now writes iac, dratio and aoi when they are nonzero, so a saved DM grid map keeps them.

cuda

  • sim/atm.cu gpu_atm2gpu: the size check compared nx*ny with a side length, so the partial-screen path (and the OOM fallback) was dead since 6cde4075c.
    • It now compares NX/NY with atm.nx/ny.
    • New atm_nxn_gpu() enlarges the GPU-hosted region to cover side-launched uplink beams.
    • The partial path matches the full screen to 6e-7 (float rounding).
    • Default runs still take the full-screen path when memory allows.
  • recon/fdpcg.cu fdpcg_mul_block_sync_half: __syncthreads() was in a loop with a divergent trip count. Every thread now runs the same number of iterations (idle ones masked), with a second barrier before the next load.
  • math/kernel.cu unwrap_phase_do: a single-block kernel was launched with a 2-D grid of many blocks, all repeating the same work. It is now a 1-D grid-stride loop launched with DIM(n,256), and uses Z(fmod) instead of fmodf so double builds stay double.

maos

  • recon_mvm.c setup_recon_mvr_mvm_iact: threads shared the invpsd/fractal FFT buffers (data race with tomo.cxxalg=1/2). Each thread now uses a shallow copy of recon/RL with private buffers.
  • GLAO indices (the recon WFS index is glao?ipowfs:iwfs):
    • petal_utils.c petal_recon: used petal_m[1] even when ittpowfs==-1. It now uses the last configured step, skips NULL petal, and indexes GA and rad2m correctly.
    • twfs.c twfs_setup_RR, twfs_setup (GRall).
    • save.c save_gradol, with sim_utils.c opening only the files that are written.
    • recon_setup.c setup_recon_focus (MVST block).
    • recon_geom.c setup_recon_dither_dm (saneai, GA), shwfs_gloc_gamp (distortion.tel2wfs), setup_recon_ploc, setup_recon_GA (dm2wfs is ndm*nwfs).
    • utils.c lgs_wfs_sph_psd.
    • parms.c: the distortion string arrays were freed with nwfsr entries (leak).
    • New: save.c save.gcov indexed gradlastol (nwfsr entries) with physical WFS. parms.c now range-checks save.gcov.
  • utils.c wfslinearity (debug tool): the r/a conversion is now applied only when gradients are actually in r/a (tCoG with radpix and srot).
  • powfs.c setup_powfs_misreg_tel:
    • An empty tel2wfs string wrote into a NULL loc_tel. One test is now used everywhere.
    • WFS without distortion get locdup(loc) so every entry is valid.
  • parms.c readcfg_siglev: wfs.wvlwts with fewer than nwfs*nwvl entries was read out of bounds. It is now validated.

skyc

  • skysim.c skysim_isky: res_aster could be reallocated while other tasks wrote to it. The index, the resize and the column write now run under simu->mutex_status, which the reader also holds.
  • genpistat.c:
    • calc_pistat leaked an empty wvfi.
    • Too few steps made navg=0 (NaN). This is now an error.
    • A leftover writebin(avgpi) in wfs_nonlinearity is removed.
  • genstars.c sortstars: read p[3] (H band) with one band, which is the next star's data. It now uses separate J+H and J comparators with const void* signatures, no function pointer cast, and const tables.

tools

  • scheduler.c CMD_STATUS: the status is now read before it is used, so an unknown pid after a restart counts its threads. The socket stays in sync when running_add fails.
  • scheduler_http.c http_context_create:
    • Reusing a slot leaked ssl, auth and cookie; it now calls http_context_remove() first.
    • The HTTPS failure path left a half-initialized slot.
    • The base64 buffer was one byte short.
  • psfgc.c: PSFs dropped in the exposure path leaked.
  • psfiris.c: idir is now range-checked; otf0/otf2 cells are freed.
  • memdbg.c (not built):
    • readlink overflow and a NULL tmp2 in call_addr2line are fixed.
    • Missing includes and P(key) uses are fixed so it compiles as C.

Not changed

  • maos/petal_utils.c keeps its existing static thread variables.
  • tools/memdbg.c still does not compile as C++.
