Detailed Description

Contains routines that will be used to talk to the scheduler. The following usage are supported:

1) by maos or skyc to ask permission to go or report status. 2) by monitor to show process information or request plotting. 3) by maos or skyc to print backtrace.

◆ scheduler_socket()

int scheduler_socket ( int dir,
int * sfd,
int id )

send a drawing sock to the scheduler for caching (dir=1) or request an existing sock (dir=-1) or new sock (dir=0) for drawing. abs(id) should be between 1 and 9999. the id send to the scheduler has the following meaning: -10000<id<0: request existing socket (drawdaemon). preferably for the same id<-10000: request new socket (drawdaemon). id>0: save socket (drawdaemon) for reuse.

Parameters
[in]dir1: send sfd for caching; -1: request an existing socket; 0: request a new socket.
[in,out]sfdThe socket to send (dir=1) or the received socket (dir=0 or -1).
[in]idDrawing id (sign is ignored).
Returns
0 on success, nonzero on failure.
